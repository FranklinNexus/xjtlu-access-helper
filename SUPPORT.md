# Support

## Where to ask

- Product defect, false diagnosis, or supported-endpoint update: open a GitHub
  issue using the bug-report form.
- Account lock, password, MFA, enrolment, course visibility, or server-side
  access policy: contact XJTLU IT. This community project cannot access or
  change university systems.
- Security vulnerability: follow [SECURITY.md](SECURITY.md) and do not post
  secrets or private reports publicly.

## Before opening an issue

1. Try the isolated System mode.
2. Run System and Direct diagnostics.
3. Review the generated `.txt` report.
4. Remove any local environment information you do not want to publish.
5. Attach the text report only when needed; never attach credentials, cookies,
   MFA codes, QR codes, OAuth/SAML parameters, or browser-profile data.

## Not supported

The project does not bypass geo-IP, WAF, account, Conditional Access, or
university policy. It does not provide a VPN or proxy and does not guarantee
that every network can reach every XJTLU service.

# Changelog

## 0.2.0 - 2026-08-08

- Add optional Edge/Chrome auto-open integration for the supported XJTLU hosts.
- Register per-service Windows URL protocols under the current user only.
- Add a one-click extension toggle and an uninstall script for the integration.

## 0.1.0 - 2026-07-28

- Add isolated Chromium profiles with extensions and sync disabled.
- Add System and browser-level Direct network modes.
- Add Learning Mall Core, XJTLU Webmail, and XJTLU website entry points.
- Add DNS, TCP 443, TLS, HTTP, redirect, clock, proxy, and VPN-signal checks.
- Add privacy-minimized text and JSON support reports.
- Add captive-portal/unexpected-redirect and WAF/access-policy classification.
- Add guarded reset for dedicated profiles only.
- Add English and Simplified Chinese documentation, security policy, and CI.
- Add support guidance, an IT-reporting template, a privacy-aware GitHub issue
  form, and ready-to-share Chinese social copy.

# 朋友圈文案

## 推荐版

学校的网站越改越唐，我这学期已经有很长一段时间没法在电脑上正常登录了：有时候
认证页一直转圈，有时候跳转直接卡死，换个网络、开着代理、装了某些浏览器扩展，表现
还都不一样。排查下来不只是一个问题，部分非大陆网络可能会被拦，浏览器扩展、Cookie、
站点存储、DNS、代理/VPN 和学校服务本身也都可能出 bug，最难受的是页面经常连一句
像样的报错都不给。

所以我干脆做了一个开源小工具 **XJTLU Access Helper**。双击以后会用一个不影响日常
浏览器的独立环境打开 Learning Mall 或学校邮箱；如果还是打不开，它会继续检查 DNS、
网络、TLS、代理、VPN、WAF/地区策略和服务端状态，并生成一份不含账号、密码、Cookie
和登录令牌的脱敏报告，方便自己排查或者直接交给 IT。

Windows 可以直接用，不需要管理员权限，也不会改全局代理或关安全软件。遇到同样问题
的同学可以试试，也欢迎提 issue 和 PR：

https://github.com/FranklinNexus/xjtlu-access-helper

（社区项目，非学校官方工具；它不会绕过学校策略，也不碰你的账号密码。）

## 更短版

学校网站登录问题实在太多了：认证页转圈、扩展冲突、Cookie/站点存储坏掉、代理/VPN、
DNS、地区策略和服务器故障都可能长得一模一样，而且经常不给正常报错。

我做了个开源的 **XJTLU Access Helper**：用独立浏览器环境打开 Learning Mall/学校邮箱，
不影响日常浏览器；打不开时还能自动做一轮脱敏诊断。Windows 直接双击使用，不需要
管理员权限，不收集账号密码。

https://github.com/FranklinNexus/xjtlu-access-helper
